# pharmacy-databese-eczane-veritaban-Oracle-
Reçeteler, ilaçlar, satışlar, stok ve personel yönetimi dahil olmak üzere gerçek dünya eczane süreçlerini modellemek için tasarlanmış Oracle SQL tabanlı ilişkisel veritabanı kütüphanesi. Proje, temiz veri modelleme, normalleştirme ve anlamlı SQL sorgularına önem vermektedir.
