## Proje Açıklaması

Bu proje, gerçek dünya eczane işlemlerini modellemek için Oracle SQL kullanılarak geliştirilmiş bir ilişkisel veritabanı kütüphanesidir.
Veritabanı tasarımı, hastalar, reçeteler, ilaçlar, satışlar, stok yönetimi,
personel ve fiyatlandırma yapıları gibi temel süreçleri kapsamaktadır.

Proje, normalizasyon, birincil-yabancı anahtar ilişkileri ve iş varlıklarının net bir şekilde ayrılması gibi uygun veri modelleme ilkelerine odaklanmaktadır.
Veritabanı şemasına ek olarak, proje, KDV dahil fiyat hesaplamaları ve satış takibi gibi gerçek hayattaki kullanım örneklerini gösteren
diziler, görünümler, tetikleyiciler ve örnek SQL sorguları da içermektedir.

Bu depo, öğrenme, tanıtım ve portföy amaçlıdır ve sağlanan SQL komut dosyaları kullanılarak kolayca kurulabilir.



## Project Description

This project is a relational database library developed using Oracle SQL to model real-world pharmacy operations.
The database design covers core processes such as patients, prescriptions, medicines, sales, stock management,
personnel, and pricing structures.

The project focuses on proper data modeling principles, including normalization, primary–foreign key relationships,
and clear separation of business entities. In addition to the database schema, the project includes sequences,
views, triggers, and example SQL queries that demonstrate real-life use cases such as VAT-inclusive price calculations
and sales tracking.

This repository is intended for learning, demonstration, and portfolio purposes, and it can be easily set up
using the provided SQL scripts.
